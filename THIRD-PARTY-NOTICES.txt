第三方组件与致谢
════════════════════════════════════════════════════════════════════

本项目是 RePKG 的 Python 重新实现。PKG / TEX 格式的解析逻辑、行为约定、
以及命令行选项设计，均源自 notscuffed 的 RePKG 项目。

════════════════════════════════════════════════════════════════════
RePKG（上游项目）
════════════════════════════════════════════════════════════════════

  项目：https://github.com/notscuffed/repkg
  协议：MIT License
  作者：notscuffed

  本项目沿用了上游的：
    · PKG 容器结构（索引表 + 裸数据）
    · TEX 容器结构（magic / header / images / mipmaps / frames）
    · LZ4 block 解压方式
    · 命令行选项命名约定（-i/--ignoreexts、-e/--onlyexts、-s/--singledir 等）

  相比上游，本项目修复了以下问题：
    · PKG 字符串长度前缀：上游 WriteStringI32Size 使用字符数而非
      UTF-8 字节数，非 ASCII 路径会损坏整个包。本项目使用字节数。
    · 增加了 Web 化能力（上传 / 预览 / 下载 / 管理）
    · media 汇总目录使用硬链接，避免 4K 视频壁纸双倍占用磁盘
